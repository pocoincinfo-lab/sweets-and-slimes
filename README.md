# Sweets & Slimes 〜お菓子の工場とスイーツ・ロケット発射計画〜

可愛いお菓子工場を建設し、おやつキャノンで腹ペコスライムを満腹にしてボヨヨンと弾き飛ばしながら、マップ中央の「超巨大スイーツ・ロケット」を完成させて宇宙へ打ち上げるシンプル自動化＆ストレスフリー防衛ゲームです。

## 主な特徴
- **神視点カメラ操作**: プレイヤーキャラ移動なし。WASD・右ドラッグで自由自在にパン、ホイールでズームして工場全体から機械1台までシームレスに確認。
- **インサーター不要の直結ベルト**: 採掘機・オーブン・ミキサー・組立機・キャノンは隣接ベルトから自動搬入＆自動搬出。ドラッグ一発で自動L字カーブ敷設。
- **ストレスゼロの「おやつ防衛」**: スライムは機械を破壊しません。おやつ弾が当たると風船のようにぷくーっと膨らみ、満腹になると幸せそうに「ボヨヨ〜ン！」と後ろのスライムを巻き込んで吹っ飛び、レア素材『キラキラ星』を落とします。
- **5段階スイーツ・ロケット発射**: ビスケット土台からショートケーキ先端ポッドまで段階的に組み上がり、クライマックスは綿あめジェット噴射で宇宙へ打ち上がります。

## 操作方法
- `W A S D` / 右ドラッグ / 中ドラッグ: カメラ移動
- マウスホイール: ズームイン / ズームアウト
- 左クリック / ドラッグ: 建物の設置（ベルトはドラッグで自動L字接続）
- `R`: 設置方向の回転
- `X`: 撤去モード切替（または建物の上で右クリック）
- `1`〜`9`, `0`: ツールバー建物クイック選択
- `H`: 中央ロケット発射台へカメラ移動
- `Space`: 一時停止 / 再開
- スライムを直接クリック: デコピンでおやつを与えて弾き飛ばす

## 開発・起動コマンド (Windows)
> Windows 環境の PowerShell ExecutionPolicy を回避するため `npm.cmd` を使用します。
```bash
npm.cmd install
npm.cmd run dev
npm.cmd run build
```

## コミットルール（Conventional Commits 日本語規約）
- **対象ブランチ**: `main`
- **形式**: `<type>: <日本語の簡潔な変更要約>`
  - `docs`: ドキュメントの作成・更新（`task.md`, `implementation_plan.md`, `walkthrough.md`, `README.md`）
  - `chore`: プロジェクト初期化、設定ファイル、依存パッケージの導入
  - `asset`: AI画像生成アセットの追加・更新
  - `feat`: 新機能・ゲームロジック・UI・演出の実装
  - `fix`: バグ修正・バランス調整
  - `refactor`: 動作を変えないコード整理
