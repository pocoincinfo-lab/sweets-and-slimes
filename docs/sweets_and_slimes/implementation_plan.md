# 『Sweets & Slimes 〜お菓子の工場とスイーツ・ロケット発射計画〜』実装計画

## 1. 企画概要・コンセプト
キャラクターが歩き回る煩雑さを排し、自由な神視点カメラ（パン・ズーム）でマップ全景を見渡しながら、可愛いパステル世界でお菓子工場を自動化する本格5階層自動化＆ストレスフリー防衛ゲーム。

- **舞台**: 鉱脈も燃料もすべてスイーツの材料でできている未知の惑星
- **最終目標**: マップ中央の「パティスリー発射台（4×4）」にベルトでお菓子パーツを納品し、**Factorio 級の5階層ピラミッド生産ツリー**を構築して**全8フェーズ**を経て『超巨大スイーツ・ロケット（パーツ100基＋黄金パフェ宇宙衛星5基）』を宇宙へ打ち上げる
- **ストレスフリー防衛**:
  - 甘い匂いに釣られて外周から「腹ペコスライム」たちがやってくるが、**機械は絶対に壊されない**。
  - ベルトで供給したおやつを「おやつキャノン」から撃ち込むと、スライムが風船のように最大2.15倍までぷくーっと膨張。
  - 満腹100%で幸せな表情になり「ボヨヨ〜ン！」と来た方向へピンボールのように吹っ飛び、後続のスライムを巻き込んで連鎖ノックバックしながらレア素材**『キラキラ星』**をドロップする。
  - 万が一ベルトに到達しても、お菓子をつまみ食いして太っちょ居眠り状態になりベルトの上を流れていくだけ。プレイヤーが直接クリック（デコピン）で弾き飛ばすこともできる。

## 2. 5階層ピラミッド生産ツリー＆全8フェーズ建造仕様

### 生産階層（全20アイテム・全15レシピ）
1. **原材料（5種）**: 小麦、砂糖結晶、イチゴ、ミルク、カカオ
2. **Tier 1 一次精錬（5種）**: クッキー、ハードキャンディ板、高純度メープルシロップ、ふわふわ生地、ホイップクリーム
3. **Tier 2 中間部品・回路（4種）**: ぷるぷる特大プリン、いちごタルト基礎回路、チョコウエハース耐熱材、もちもちタピオカ演算素子
4. **Tier 3 ロケット3大中間素材＆反応炉（4種）**: 超軽量キャンディ複合装甲（低密度構造材枠）、10段ギガパンケーキ燃料、虹色マカロン演算基板（RCU枠）、特大いちごショート反応炉
5. **Tier 4 最終ロケット部品＆衛星（2種）**: スター・ロケットパーツ（複合装甲＋パンケーキ燃料＋マカロン基板を統合）、黄金パフェ宇宙衛星

## 3. 技術スタック・描画設計
- **フレームワーク / 言語**: TypeScript + Vite + HTML5 Canvas 2D + CSSグラスモーフィズムUI + lucide
- **ハイブリッド描画方式**:
  - **マップ上の機械・アイテム・スライム・エフェクト**: OffscreenCanvas にベクター＆グラデーション・光沢付き 128×128 スプライトとして事前ベイクし、60FPSでぷにぷに伸縮（Squash & Stretch）とドロップシャドウを描画。
  - **AI生成ビジュアル**: タイトルバナー、ロケット紋章、キングスライム紋章を `public/assets/` に生成し、`assetLoader.ts` の外周フラッドフィル透過処理を通して UI・図鑑・勝利モーダルに表示。
- **サウンド**: Web Audio API プロシージャルシンセサイザー（外部音声ファイル不要）。
- **シミュレーション倍速・セーブ機能**: `1x / 2x / 5x` サブステップ倍速切替、LocalStorage (`v2`) への自動保存・手動セーブ・リセット対応。

## 4. コミットルール（Conventional Commits 日本語規約）
- **ブランチ**: `main`
- **フォーマット**: `<type>: <日本語の簡潔な変更要約>`
  - `docs`: ドキュメントの作成・更新（`task.md`, `implementation_plan.md`, `walkthrough.md`, `README.md`）
  - `chore`: プロジェクト初期化、設定ファイル、依存パッケージの導入
  - `asset`: AI画像生成アセットの追加・更新
  - `feat`: 新機能・ゲームロジック・UI・演出の実装
  - `fix`: バグ修正・バランス調整
  - `refactor`: 動作を変えないコード整理
- **運用方針**: フェーズまたはまとまった機能単位で段階的にコミットし、検証後にプッシュする。
