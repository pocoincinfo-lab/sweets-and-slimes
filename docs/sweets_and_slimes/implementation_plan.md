# 『Sweets & Slimes 〜お菓子の工場とスイーツ・ロケット発射計画〜』実装計画

## 1. 企画概要・コンセプト
キャラクターが歩き回る煩雑さを排し、自由な神視点カメラ（パン・ズーム）でマップ全景を見渡しながら、可愛いパステル世界でお菓子工場を自動化するシンプル自動化＆ストレスフリー防衛ゲーム。

- **舞台**: 鉱脈も燃料もすべてスイーツの材料でできている未知の惑星
- **最終目標**: マップ中央の「パティスリー発射台（4×4）」にベルトでお菓子パーツを納品し、全5フェーズを経て『超巨大スイーツ・ロケット』を宇宙へ打ち上げる
- **ストレスフリー防衛**:
  - 甘い匂いに釣られて外周から「腹ペコスライム」たちがやってくるが、**機械は絶対に壊されない**。
  - ベルトで供給したおやつを「おやつキャノン」から撃ち込むと、スライムが風船のように最大2.2倍までぷくーっと膨張。
  - 満腹100%で幸せな表情になり「ボヨヨ〜ン！」と来た方向へピンボールのように吹っ飛び、後続のスライムを巻き込んで連鎖ノックバックしながらレア素材**『キラキラ星』**をドロップする。
  - 万が一ベルトに到達しても、お菓子をつまみ食いして太っちょ居眠り状態になりベルトの上を流れていくだけ。プレイヤーが直接クリック（デコピン）で弾き飛ばすこともできる。

## 2. 5段階スイーツ・ロケット建造仕様

| フェーズ | 建造部位 | 必要納品素材＆コスト |
| --- | --- | --- |
| **Phase 1** | ビスケット発射台基礎 | 焼きたてクッキー ×12、シュガークリスタル ×8、キラキラ星 ×2 |
| **Phase 2** | キャンディ装甲胴体 | ハードキャンディ装甲 ×12、ふわふわ生地 ×10、キラキラ星 ×5 |
| **Phase 3** | メープル推進ブースター | 高純度メープルシロップ ×10、チョコウエハース装甲 ×10、キラキラ星 ×8 |
| **Phase 4** | ショートケーキ先端ポッド | いちごタルト ×10、特大いちごショート ×6、キラキラ星 ×12 |
| **Phase 5** | スターエンジン点火＆発射 | 10段ギガパンケーキ ×6、キラキラ星エンジンコア ×4、キラキラ星 ×18 |

Phase 5 達成で15秒の「最終おやつパレード＆打ち上げカウントダウン」が発生し、キングスライム軍団を迎撃したのち、大量の綿あめスモークと星パーティクルを噴き上げて成層圏へロケットが打ち上がる。

## 3. 技術スタック・描画設計
- **フレームワーク / 言語**: TypeScript + Vite + HTML5 Canvas 2D + CSSグラスモーフィズムUI + lucide
- **ハイブリッド描画方式**:
  - **マップ上の機械・アイテム・スライム・エフェクト**: OffscreenCanvas にベクター＆グラデーション・光沢付き 256×256 スプライトとして事前ベイクし、60FPSでぷにぷに伸縮（Squash & Stretch）とドロップシャドウを描画。
  - **AI生成ビジュアル**: タイトルバナー、ロケット紋章、キングスライム紋章を `public/assets/` に生成し、`assetLoader.ts` によるコーナー背景クロマキー自動透過・丸角バッジマスクを通して UI・図鑑・勝利モーダルに表示。
- **サウンド**: Web Audio API プロシージャルシンセサイザー（外部音声ファイル不要）。
- **セーブ機能**: LocalStorage への自動保存・手動セーブ・リセット対応。

## 4. コミットルール（Conventional Commits 日本語規約）
- **ブランチ**: `main`
- **フォーマット**: `<type>: <日本語の簡潔な変更要約>`
  - `docs`: ドキュメントの作成・更新（`task.md`, `implementation_plan.md`, `walkthrough.md`, `README.md`）
  - `chore`: プロジェクト初期化、設定ファイル、依存パッケージの導入
  - `asset`: AI画像生成アセットの追加・更新
  - `feat`: 新機能・ゲームロジック・UI・演出の実装
  - `fix`: バグ修正・バランス調整
  - `refactor`: 動作を変えないコード整理
- **運用方針**: フェーズまたはまとまった機能単位で段階的にコミットし、検証後にプッシュする。
